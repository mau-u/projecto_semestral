DSY1104 — Evaluación Parcial 3
Proyecto: Mil Sabores

Este ZIP reúne el proyecto original del estudiante y las incorporaciones de la evaluación:
- Frontend React original conservado.
- Backend Spring Boot + MySQL.
- Docker Compose.
- Cliente REST para catálogo y autenticación.
- ERS, manual de usuario, documentación API e integración, planilla de endpoints, diagramas, matriz de pruebas y guion de presentación.

Inicio rápido:
1) Extraer el ZIP.
2) Abrir PowerShell en la carpeta raíz.
3) Ejecutar: docker compose up --build
4) Abrir http://localhost
